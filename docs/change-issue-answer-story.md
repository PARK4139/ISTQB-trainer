# Issue 답안 변경

학습자로서, 이미 답한 Issue에서도 다른 보기를 선택해 답안을 바꾸고 싶다. 점수보다 개념 이해가 중요하므로 초기화 없이 선택과 해설을 비교하며 학습할 수 있어야 한다.

## 수용 기준

- AC-ANSWER-01: DAY 01~06 Issue에서 정답·오답 여부와 관계없이 다른 보기를 다시 선택할 수 있다. 선택 즉시 내 선택, 정오답 표시와 해설을 갱신하고 최신 답안을 저장한다. 새로고침해도 최신 선택을 유지하며 다른 Issue 답안은 보존한다.
- 정답으로 접힌 Issue도 펼쳐서 답안을 바꿀 수 있다.
- DAY 07 모의고사와 공식 시험의 제출 규칙은 기존대로 유지한다.
