# 전체 문자열 치환과 고급설정

## US-ALL: 앱 전체 문자열 치환

학습자로서 “프로젝트”를 선택하고 Ctrl+Shift+L을 눌러 앱이 소유한 모든 문자열을 “Project”로 바꾸고 싶다. 문구가 저장된 위치나 종류에 따라 누락되지 않고 용어를 일관되게 변경하기 위해서다.

- AC-ALL: web/, scripts/, content/, notes/ 아래 UTF-8 텍스트 파일과 run.cmd, SQLite의 모든 사용자 테이블 문자열 값을 정확 일치로 치환한다. 본문·메모·코드·속성·URL·ID·메타데이터를 구분하여 제외하지 않는다. 파일명, 바이너리 이미지, SQLite 구조 자체와 외부 사이트·브라우저 화면은 문자열 값이 아니다.
- Ctrl+Shift+L 시 대상을 고정한다. 위치·개수를 표시하고 입력 즉시 현재 화면에 반영하며 별도 미리보기나 적용 버튼은 없다. 마지막 입력 후 400ms에 저장한다. 새 문자열은 재검색하지 않는다.
- 파일과 DB를 함께 저장하고 재시작·재빌드 시 유지한다. 스크립트 변경은 다음 서버 실행부터 적용된다. 실행 중인 스크립트는 편집 도중 재실행하지 않는다.
- 이 요구는 기존 AC-02의 비문구 제외, AC-11의 원문 유지보다 우선한다. 변경 전 원문은 별도 복구 사본에서 보존한다. 체크섬·메모 버전·내보내기 해시는 저장 결과에 맞게 다시 계산한다.

## US-SETTINGS: 고급설정 접근과 편집 모드 제어

학습자로서 화면 상단의 고급설정에서 전체 문자열 치환을 켜거나 끄고 싶다. 메모 패널의 표시 여부와 관계없이 기능과 현재 활성화 상태를 찾을 수 있어야 한다.

- AC-SETTINGS: 상단 고급설정 버튼은 좁은 화면과 접힌 메모 패널에서도 보인다. 전체 문자열 치환은 기본 OFF이며 선택은 새로고침 후 유지한다. ON 상태는 상단에 계속 표시한다.
- 코드·URL·ID도 변경되며 동작에 영향을 줄 수 있음을 스위치 옆에 설명한다. OFF에서는 기존 메모 Ctrl+Shift+L을 유지한다. 등록 문구만 편집하는 기존 설정과 전체 문자열 모드는 동시에 켜지지 않는다.
- 서버가 없으면 활성화하지 않고 run.cmd 실행을 안내한다. OFF 전환 시 저장을 시도하고 실패하면 편집 세션과 초안을 보존한다. 변경 이력·복원·미저장 초안 복구를 제공한다.

## US-RECOVERY: 실행 불가능한 변경도 복구

학습자로서 코드나 ID 치환으로 웹이 실행되지 않아도 변경 묶음을 되돌리고 싶다.

- AC-RECOVERY: 치환 범위 밖의 .ctfl-recovery/에 원본·변경 이력·독립 복구 스크립트를 보관한다. 일반적으로 run.cmd recover로 최근 묶음을 복원한다. run.cmd 자체가 손상된 경우 PowerShell에서 .ctfl-recovery/recover.ps1을 실행한다. 서버를 종료한 뒤 복원한다.
- 저장 전 충돌 검사와 작업 저널을 사용한다. 저장 실패는 파일·DB를 원복하고 성공으로 표시하지 않는다. 중단된 저장은 다음 실행에서 원복한다. 완료된 변경의 복원은 후속 변경을 감지하면 거절한다.
- 복구 사본과 Git·문서·검증 자료는 앱 실행 원본이 아니므로 치환하지 않는다. 자동 Git 커밋·push는 하지 않는다.

## US-INLINE: 메모 편집기에서 웹 전체 문구를 바로 수정

학습자로서 별도 치환 창을 열지 않고, 고급설정에서 전체 문구 편집을 켠 뒤 Ctrl+Shift+L로 선택한 문구를 기존 학습 메모 편집기에서 바로 고치고 싶다. 익숙한 메모 입력 흐름을 그대로 사용하면서 선택된 전체 문구에 수정이 즉시 반영되기를 원한다.

- AC-INLINE-01: 전체 문구 편집 ON에서 메모 또는 웹 문구를 선택하고 Ctrl+Shift+L을 누르면 별도 입력 패널 없이 기존 학습 메모 편집기가 입력 표면이 된다.
- AC-INLINE-02: 메모 편집기에서 입력·삭제·붙여넣기·한글 IME를 사용할 때 대상 전체가 즉시 바뀌고 저장된다. 미리보기나 적용 버튼을 요구하지 않는다.
- AC-INLINE-03: 치환 입력 버퍼는 학습 메모 원문으로 저장되지 않는다. 세션을 끝내면 서버의 최신 메모 원문을 다시 읽고 메모 편집기에 표시한다.
- AC-INLINE-04: Esc 종료, 저장 실패 재시도, 미저장 초안 복구, 기존 메모 선택·스크롤 복원 동작을 유지한다.
- AC-INLINE-05: 전체 문구 편집 OFF에서는 기존 메모 다중 선택 동작을 유지한다.
